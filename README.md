# Mastrox 3D Models

โมเดล 3 มิติของเครื่องจักร Mastrox (Rakete, Booster, Moon, Nova, Nebula, Aurora, Cold Presso, Glue Spreader, VAir) สร้างด้วย three.js

## เปิดดู
```
npx http-server -p 5181 -c-1
```
- `index.html`: ดูโมเดล ดูแอนิเมชัน และ export ไป SketchUp / Blender / OBJ / STL
- `drawing.html`: ภาพนิ่ง 2D 4 ด้าน (หน้า/หลัง/ซ้าย/ขวา) สีเรียบ เส้นขอบดำคม พร้อมเส้นบอกขนาด บันทึก PNG รุ่นเดียวหรือทุกรุ่นเป็น zip (โค้ดวาดอยู่ใน `views2d.js`)
- `editor.html`: แก้ไขชิ้นส่วน (ย้าย หมุน สเกล สี ซ่อน ลบ ทำซ้ำ) สร้าง **กล่อง / ท่อ / สายไฟ** ทำ **แอนิเมชันคีย์เฟรม** (แถบเวลาด้านล่าง) แล้วบันทึกเป็น `edits-<รุ่น>.json` (การแก้ไข + คีย์เฟรมในไฟล์เดียว) ปุ่ม “ตรวจ & Export” เปิดหน้าดูตัวอย่างไฟล์ก่อน export (เลือกรูปแบบ, Low poly, ท่าที่เวลาไหน, ใส่แอนิเมชันใน .glb)
  - เครื่องมือ: `V` เลือก · `B` กล่อง (คลิกหรือลากบนพื้น) · `T` ท่อ / `L` สายไฟ (คลิกทีละจุด, `Shift` ขึ้นแนวตั้ง, `Enter` จบ) · ลากจุดสีส้มบนท่อ/สายเพื่อแก้แนว
  - แอนิเมชัน: เลือกชิ้น → `K` ใส่คีย์ → คลิกแถบเวลาไปเวลาอื่น → ย้ายชิ้น (ชิ้นที่มีคีย์แล้วจะใส่คีย์ให้เอง) → `Space` เล่น · ลากรูปเพชรเพื่อย้ายคีย์ คลิกขวาเพื่อลบ
  - หน้าโมเดล (index.html) แสดงชิ้นที่สร้างและเล่นคีย์เฟรมตามที่บันทึกไว้ (`anim.js`)
- `list.html`: รายการเครื่องทั้งหมด
- `compare.html`: เทียบระดับโมเดลทุกรุ่น เรียงจากหยาบไปเหมือนจริง: กล่องเปล่า → ก้อนใหญ่ → ก้อนเหลี่ยม → โมเดลเต็ม → รูปถ่ายจริง (มุมกล้องเดียวกัน คลิกช่องเพื่อหมุนดู กด 1–4 สลับระดับ)

## ก้อนเหลี่ยม (สำหรับ Factory Simulator)
`machines/blocky.js` แปลงโมเดลเป็นก้อน ทุกระดับมีโลโก้ mastrox (อาร์ตเวิร์กจริงจาก Docs\Logo) ตำแหน่งและขนาดเดียวกับโลโก้บนโมเดลเต็ม ย้ายมาแปะบนผิวก้อน (`label: false` ปิดได้; กล่องเปล่าใช้โลโก้ใหญ่สุดด้านละหนึ่งอัน)
- `plainBox(machine)`: กล่องเทาขนาดจริง ขีดส้มขอบบนด้านหน้า
- `toBlocky(machine, { level: 'chunky' })`: ก้อนใหญ่ไม่กี่ก้อน รวมก้อนสีเดียวกันที่ติดกัน ตัดก้อนเล็กกว่า 45 ซม. และราง/แถบยาวบาง
- `toBlocky(machine, { level: 'blocky' })`: ทุกชิ้นใหญ่กว่า 12 ซม. เป็นกล่องเอียงตามชิ้น (กฎเดียวกับ Factory Simulator)
- `blockyMachine(machine, { level })`: คืน record แบบเดียวกับ `MODELS[id]()` แต่ object เป็นก้อน
- ได้ Group ที่วางตรงกับโมเดลเต็ม หรือ `center: true` ให้กึ่งกลางฐานอยู่ที่ origin; ด้านหน้าคือด้านที่ `views.a` มอง
- ฝาอะคริลิกดันออก 2 ซม. (`glassPad`) ไม่ให้กรอบทึบบังจนฝาส้มหาย

## Low poly (เอาไปวางในผังโดยไม่กระตุก)
ใน index.html กด "รายละเอียด: Low poly" (หรือเปิด `index.html?m=<รุ่น>&lod=low`) แล้ว export ได้ทุกแบบ ปุ่ม "Low poly ทุกรุ่น" ได้ไฟล์ .glb ทุกเครื่องใน zip เดียว
- `lowpoly.js`: ตัดชิ้นเล็ก (น็อต ปุ่ม สายลมเส้นเล็ก) ลดเหลี่ยมของชิ้นกลม รวมชิ้นสีเดียวกันเป็นก้อนเดียว เก็บโลโก้/ตัวหนังสือ และจุดยืนทำงานไว้เหมือนเดิม
- เป็นโมเดลนิ่ง ไม่มีแอนิเมชัน ไม่มีแผ่นไม้บนโต๊ะ
- Rakete ~18k สามเหลี่ยม / ~70 ชิ้น (จาก ~230k / ~900), เครื่องอื่น 1k–7k สามเหลี่ยม

## โครงสร้าง
- `machines/`: โค้ดสร้างโมเดลแต่ละรุ่น (`registry.js` คือรายชื่อรุ่น, Rakete ทั้ง 4 รุ่นมาจาก `rakete-real.js`)
- `data/machines.js`: ข้อมูลรุ่น ราคา และขนาดจากโบรชัวร์
- `edits.js`: ระบบเก็บการแก้ไขจาก editor
- `export.js`: export เป็น .dae / .obj / .glb / .stl
- `FIXES.md`: บันทึกสิ่งที่แก้

## จุดยืนทำงาน (Operator zone)
ทุกรุ่นมีแผ่นสีเหลืองขอบเหลือง-ดำพร้อมรอยเท้าบนพื้น ตรงหน้าจอ/แผงควบคุม บอกว่าคนยืนทำงานตรงนี้ (ตำแหน่งกำหนดใน `machines/registry.js` ตัวแปร `ZONES`, ปุ่มเปิด/ปิดใน index.html, ย้ายได้ใน editor)

เว็บที่เอาโมเดลไปใช้หาตำแหน่งได้จาก:
- โค้ด three.js: `machine.operatorZones` หรือ `machine.object.userData.operatorZones`
- ไฟล์ .glb: node ชื่อ `OperatorZone` มี `extras.operatorZone` และ node ราก (ชื่อรุ่น) มี `extras.operatorZones`
- ไฟล์ .dae / .obj: ชิ้นส่วนชื่อขึ้นต้นด้วย `OperatorZone`

ข้อมูล (หน่วยเมตร, Y ขึ้น): `{ position: [x, y, z], look: [x, z], size: [กว้าง, ลึก] }`, `position` คือกลางแผ่นบนพื้น, `look` คือทิศที่คนหันหน้าไปหาเครื่อง
